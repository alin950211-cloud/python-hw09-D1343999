## 問題一

因為桌遊名單雖然有4筆資料，但是Amy重複報名，所以實際只有3個人。使用 set 可以去掉重複的名字，所以、費用只算3人。list 會保留原本的順序和重複資料，但轉成 set 後就不會保留順序，也沒辦法知道原本重複幾次。

## 問題二

因為兩場活動都是 Amy、Ben、Cora 這3個人，所以聯集只有3人，交集也是3人，差集則是空集合。但每個人都有參加兩場，所以是 3 + 3 = 6 人次。費用為桌遊 3 × 120 = 360 元，電影 3 × 80 = 240 元，總共 600 元。
